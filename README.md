# 🗂️ File Organizer Automation Script (Python)

This project is a simple but powerful **file organization tool** written in Python.  
It automatically sorts files in a selected folder into organized subfolders based on their file extensions.

Perfect for:
- Cleaning desktops  
- Organizing download folders  
- Automating repetitive sorting tasks  
- Practicing Python for DevOps automation  

---

## 🚀 Features
- Automatically creates folders for:
  - `.csv` files  
  - `.pdf` files  
  - `.txt` files  
- Moves files into the correct folders
- Prevents overwriting or moving directories
- Clean, modular, and readable Python code

---

## 🧠 Technologies Used
- Python 3
- `os` module — interacts with the file system  
- `shutil` — moves files
